# Invite Shiver

Experiência interativa de **convite / envelope** que revela um vídeo HTML real.

## Stack

- Next.js 15 (App Router)
- React 19
- GSAP 3 (timeline cinematográfica)
- CSS Modules

## Desenvolvimento

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Componente

`components/VideoInvitation/`

Ver detalhes em [`documents/video-invitation.md`](documents/video-invitation.md).
